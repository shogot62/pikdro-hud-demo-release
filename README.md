# PikDro HUD Demo

対象バージョン: `0.1.0-demo-309`（versionCode `309`）

PikDro HUD Demoは、Uber Driverのオファー画面に表示された金額・距離・予定時間をもとに、距離単価や時間単価などの判断補助情報をHUD表示するAndroid向けデモアプリです。

本アプリは配達サービス各社の公式アプリではなく、提携・承認・認定・協賛を受けたものではありません。オファーの自動受諾・自動拒否・自動タップは行いません。

## ダウンロード

最新版はGitHub Releasesから取得してください。

1. Releasesで最新の通常リリースを開きます。
2. `PikDro-HUD-demo-<tag>.apk` をダウンロードします。
3. SHA-256を確認する場合は `SHA256SUMS.txt` を利用します。
4. Android端末でAPKを開き、標準インストーラーの案内に従います。

## アップデート

Demo版はGitHub Releasesの `update.json` を確認し、端末上のversionCodeより新しい版がある場合に案内します。APKのダウンロードはユーザーが同意した後だけ開始し、SHA-256が一致した場合に限りAndroid標準インストーラーを開きます。サイレントインストールや強制更新は行いません。

## 配達仲間へ共有

設定画面の末尾にある「PikDro HUDを共有」を開くと、この公開配布ページのQRコードを表示できます。通常は折りたたまれており、配達前の設定操作を妨げません。

同じ画面からGitHubページを開くか、Androidの共有シートへ公開URLを渡すこともできます。共有内容にアプリ設定、診断ログ、保存画像は含まれません。
