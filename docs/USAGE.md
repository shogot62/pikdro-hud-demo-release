# PikDro HUD Demo の使い方

最終更新日: 2026年7月15日  
対象バージョン: `0.1.0-demo-308`（versionCode `308`）

## 動作対象

- Android 8.0（API 26）以上
- Uber Driver
- Google Play外から配布されるDemo APK

その他の配達アプリは現行v0.1の動作対象ではありません。

## インストール

1. Demo配布リポジトリのGitHub Releasesを開きます。
2. 最新の通常リリースからAPKをダウンロードします。
3. 必要に応じて `SHA256SUMS.txt` とAPKのSHA-256を照合します。
4. APKを開き、Android標準インストーラーの案内に従います。

端末やブラウザによっては「不明なアプリのインストール」の許可が必要です。許可対象はAPKを開いたブラウザ、ファイルアプリ、またはPikDro HUD Demoです。

## 初期設定

1. PikDro HUD Demoを起動します。
2. 「アクセシビリティ設定を開く」からPikDro HUD Demoを有効にします。
3. 「オーバーレイ設定を開く」から「他のアプリの上に表示」を許可します。
4. アプリへ戻り「HUD有効化」をONにします。
5. 「Uber Driverを開く」からUber Driverを起動します。

通知アクセス、位置情報、カメラ、マイク、連絡先、広範なストレージ権限は通常利用に不要です。

## HUDの動作

Uber Driverのオファー候補を検知すると、必要なタイミングだけスクリーンショットを取得し、オファーカードの必要範囲へ切り出して端末内OCRを行います。金額・距離・予定時間を取得できた場合に、設定に応じた判断補助情報をHUD表示します。

表示例:

- 距離単価
- 分単価
- 時給換算
- 1時間あたりの配達件数ペース
- 車・バイクの消費燃料目安
- 自転車・徒歩の消費カロリー目安

OCRや画面形式の影響で値を安全に確定できない場合は、偽の値を表示せずHUDを出さないことがあります。

## ミニアイコン

HUD監視中はミニアイコンが表示される場合があります。

- ドラッグ: 表示位置を移動
- 短くタップ: 現在のオファー画面を手動確認
- 長押し: PikDro HUD Demoを開く

手動確認も配達アプリのボタン操作は行いません。

## 主な設定

- HUD表示時間: 1〜60秒
- 車両: 車/バイク、電動自転車、ママチャリ、クロス/ロードバイク、徒歩
- 燃費・体重
- HUD枠線の評価基準と色
- ライト・ダークテーマ
- 音声読み上げとテンプレート
- HUDプレビュー

体重が未入力の場合、消費カロリー計算には60kgを使用します。

## PikDro HUDを共有する

設定画面の末尾にある「PikDro HUDを共有」は、通常は折りたたまれています。配達仲間へ案内するときだけ開いてください。

- QRコード: このGitHub公開配布ページを別の端末で開きます。
- GitHubを開く: 端末のブラウザまたはGitHubアプリで公開配布ページを開きます。
- リンクを共有: 公開URLと案内文だけをAndroidの共有シートへ渡します。共有先の選択と送信はユーザーが行います。

アプリ設定、診断ログ、保存画像、配達情報は共有内容に含まれません。運転中・走行中は操作しないでください。

## 画像保存

「オファー画像の保存」をONにすると、HUD表示に使った確認用のOCR入力ROI画像を `Pictures/PikDro` に保存します。画像には配達アプリの画面情報が含まれる可能性があります。

アプリ内では、画像の確認、削除、トリミング、縦結合、単価結合を利用できます。`Pictures/PikDro` の確認用画像は診断アップロードには含まれません。

## 診断ログと不具合報告

不具合を報告する場合:

1. 「診断ログ」で詳細診断をONにします。
2. 問題を再現します。
3. アプリへ戻り「アップロード」を押します。
4. 個人情報を含めず、発生状況だけを入力して送信します。

住所、店舗名、顧客名、電話番号、配達先、注文番号、メールアドレスを書かないでください。送信内容の詳細は [PRIVACY.md](PRIVACY.md) を確認してください。

## アップデート

Demo版では「最新版を確認」から手動確認できます。新しい版がある場合、ユーザーが「ダウンロード」を選んだ後にAPKを取得し、SHA-256一致後にAndroid標準インストーラーを開きます。

自動チェックは行われる場合がありますが、自動ダウンロード、サイレントインストール、強制更新は行いません。
