# PikDro HUD Demo の使い方

## PikDro HUD Demo とは

PikDro HUD Demo は、Uber Driver のオファー画面に表示される金額・距離・予定時間などをもとに、配達判断を補助するHUDを画面上に表示するデモ版アプリです。

数字や計算が苦手な場合でも、単価やペースをすばやく確認しやすくすることを目的としています。

本アプリは、配達サービス各社の公式アプリではありません。
また、配達の受諾・拒否を自動で行うものではありません。

## 現在の対応アプリ

現時点の主な対応対象は以下です。

* Uber Driver

その他の配達アプリへの対応は、今後の検証対象です。

## 主な表示内容

PikDro HUD Demo は、オファー画面から読み取れた情報をもとに、主に以下の情報を表示します。

* 距離単価
* 分単価
* 時給換算
* 1時間あたりの配達件数ペース
* 消費燃料、または消費カロリー

表示内容は、オファー画面から読み取れた情報や設定内容によって変わる場合があります。

## 基本的な使い方

1. PikDro HUD Demo をインストールします。
2. PikDro HUD Demo を起動します。
3. 必要な権限を許可します。
4. アプリ内の「HUD有効化」をONにします。
5. 「Uber Driverを開く」からUber Driverを起動します。
6. Uber Driver上でオファー画面が表示されると、PikDro HUDが判断補助情報を表示します。

HUDを利用するには、PikDro HUD Demo 側で「HUD有効化」がONになっている必要があります。

## 必要な権限

PikDro HUD Demo では、主に以下の権限を使用します。

### アクセシビリティ権限

Uber Driver の画面変化を検知し、オファー画面が表示された可能性を判断するために使用します。

また、必要に応じて画面内容の確認やスクリーンショット取得を行い、OCRによる読み取り処理に利用します。

本アプリは、配達アプリの操作を自動で行うものではありません。

### 他のアプリの上に表示する権限

Uber Driver の画面上に、PikDro HUDを重ねて表示するために使用します。

この権限が許可されていない場合、HUDやミニアイコンを表示できません。

### 不明なアプリのインストール許可

GitHub Releases からAPKをインストールする場合、Android端末側で「不明なアプリのインストール」を許可する必要がある場合があります。

この許可は、APKをインストールするためのAndroid側の設定です。

## 画面構成

PikDro HUD Demo の設定画面には、主に以下の項目があります。

### アクション

HUDの有効化と、Uber Driverの起動を行います。

* HUD有効化
* HUD監視状態の確認
* Uber Driverを開く

「HUD有効化」をONにすると、Uber Driverのオファー画面検知とHUD表示が有効になります。

必要な権限が不足している場合は、HUDをONにできない場合があります。

### 表示設定

HUDの表示内容や見た目に関する設定を行います。

設定できる項目は主に以下です。

* HUD表示時間
* 車両設定
* 燃費
* 体重
* カラーコーディング設定
* テーマ

#### HUD表示時間

オファー画面が消えた後も、指定した秒数だけHUD表示を維持します。

設定範囲は 1〜60秒です。

#### 車両設定

配達に使用する移動手段を選択します。

選択できる項目は以下です。

* 車/バイク
* 電動自転車
* ママチャリ
* クロス/ロードバイク
* 徒歩

車/バイクを選択した場合は、燃費をもとに消費燃料を計算します。
自転車や徒歩を選択した場合は、体重と予定時間をもとに消費カロリーを計算します。

#### 燃費

車/バイク選択時に使用します。

入力した燃費をもとに、オファー距離から消費燃料の目安を計算します。

#### 体重

自転車・徒歩選択時に使用します。

入力した体重をもとに、消費カロリーの目安を計算します。
未入力の場合は、標準値として60kgが使用されます。

#### カラーコーディング設定

HUDの枠色を変化させる基準を設定します。

基準にできる指標は以下です。

* Km単価
* 分単価
* 時給換算

選択した指標に対して、低・標準・高のしきい値を設定できます。
HUDの枠色は、設定したしきい値に応じて変化します。

#### テーマ

アプリ画面の外観を変更できます。

* システム設定に従う
* 常にライト
* 常にダーク

### 読み上げ設定

HUD表示内容を音声で読み上げるための設定です。

以下の項目を設定できます。

* 音声読み上げのON/OFF
* 読み上げテンプレート
* テスト再生

読み上げテンプレートには、以下のような変数を挿入できます。

* 単価
* 距離
* 時間
* Km単価
* 分単価
* 時給
* 消費燃料または消費カロリー
* ペース

「テスト再生」を押すと、サンプル値で読み上げ内容を確認できます。

### HUDプレビュー

実際のオファー画面を待たずに、HUDの表示イメージを確認できます。

プレビューでは以下の値を動かせます。

* 金額
* 距離
* 時間

「HUDプレビュー表示」を押すと、現在の設定を反映したHUDが画面上に表示されます。
「プレビューを閉じる」を押すと、プレビュー表示を終了します。

HUDプレビューを使用するには、オーバーレイ権限が必要です。

### 権限設定

PikDro HUD Demo に必要な権限の状態を確認できます。

表示される項目は以下です。

* アクセシビリティ
* オーバーレイ

権限が未設定の場合は、各設定画面を開いて許可してください。

### 画像保存設定

OCR入力画像を端末内に保存するための設定です。

画像保存をONにすると、OCRに使用した入力画像が端末の以下の場所に保存されます。

```text
DCIM/PikDro
```

この画像は、ユーザーが読み取り状況を確認するためのものです。
診断アップロードでは、このDCIM/PikDro内の確認用画像は送信されません。

画像保存設定では、以下の操作ができます。

* 画像保存のON/OFF
* 最新画像の確認
* 保存画像一覧の確認
* 保存画像の削除
* 複数画像のレシート結合

レシート結合では、保存された複数の画像を縦方向に連結し、1枚の画像としてまとめることができます。

長いレシートや複数回に分かれて保存された画像を確認したい場合に利用できます。

画像には、配達アプリの画面情報が含まれる可能性があります。
取り扱いには注意してください。

### 診断ログ

不具合調査のための診断機能です。

通常利用時に常に確認するための機能ではなく、HUDが表示されない、読み取り結果がおかしい、挙動が不安定などの問題が発生したときに使用します。

診断ログでは、以下の操作ができます。

* 診断ログのON/OFF
* ログ用画像の確認
* ログの表示
* ログのクリア
* ログと診断情報のアップロード

ログ出力レベルは、主に以下から選択します。

* OFF
* 詳細診断

OFFの場合、診断ログは書き込まれません。
不具合を報告する場合は、詳細診断をONにしてから再現操作を行ってください。

## 不具合を報告する流れ

HUDが出ない、数値がおかしい、限定オファーが認識されないなどの不具合がある場合は、以下の流れで報告してください。

1. PikDro HUD Demo を開きます。
2. 「診断ログ」を開きます。
3. ログ出力を「詳細診断」にします。
4. Uber Driverで不具合が発生する操作を行います。
5. PikDro HUD Demo に戻ります。
6. 「診断ログ」から「アップロード」を押します。
7. 不具合の内容をコメント欄に入力します。
8. 「送信する」を押します。

送信された診断情報は、不具合の原因調査と修正に利用します。

コメントには、できるだけ以下のような内容を書いてください。

* 何をしようとしていたか
* どの画面で発生したか
* HUDが出なかったのか、数値がおかしかったのか
* 何回くらい発生したか
* 再現しやすい条件があるか

例:

```text
オファー画面は表示されていたが、HUDが出ませんでした。
```

```text
HUDは表示されたが、距離単価が明らかにおかしい値になりました。
```

```text
限定オファーの画面で、何度かHUDが表示されませんでした。
```

## 診断アップロードに含まれる可能性がある情報

診断アップロードでは、不具合調査のために以下の情報が含まれる場合があります。

* アプリのバージョン
* 端末情報
* OSバージョン
* 権限状態
* OCRの成功/失敗
* HUD表示状態
* エラー情報
* 診断ログ
* ログ用OCR画像
* ユーザーが入力した不具合コメント

ログ用OCR画像は、アプリ内の診断用保存領域に保存された画像です。
ユーザー確認用として `DCIM/PikDro` に保存された画像は、診断アップロードには含まれません。

アップロードが成功した場合、送信済みの診断ログとログ用画像は端末内から削除されます。

## コメント入力時の注意

不具合コメントには、個人や場所を特定できる情報を書かないでください。

入力しないでほしい情報の例:

* 住所
* 店舗名
* 顧客名
* 電話番号
* 配達先
* 注文番号
* 個人を特定できる内容

コメント欄には、不具合の状況だけを書いてください。

## ミニアイコンについて

HUD監視がONで、PikDro HUD Demo本体画面以外を表示しているとき、画面上にPikDroのミニアイコンが表示される場合があります。

ミニアイコンでは、以下の操作ができます。

* ドラッグして位置を移動
* タップして手動チェック
* 長押ししてPikDro HUD Demoを開く

手動チェックは、オファー画面が表示されているのにHUDが出ない場合などに使用します。

短時間に連続してタップしても、一定時間は再チェックされない場合があります。

## HUDの操作

HUDには、閉じるボタンや折りたたみボタンが表示される場合があります。

* 閉じるボタン: HUDを非表示にします。
* 折りたたみボタン: HUDの表示を簡略化します。

HUDは、設定した表示時間が経過すると自動的に非表示になる場合があります。

## 利用時の注意

* 配達中、運転中、走行中に画面を注視しないでください。
* 安全確認と交通ルールを最優先してください。
* 各配達サービスの利用規約を確認し、自己責任で利用してください。
* 表示内容や計算結果が常に正確であるとは限りません。
* 読み取りに失敗した場合、HUDが表示されない、または一部の数値が表示されない場合があります。
* 不安定な動作や重要な不具合を確認した場合は、利用を中止してください。

## よくある確認ポイント

### HUDが表示されない場合

以下を確認してください。

* PikDro HUD Demo の「HUD有効化」がONになっているか
* アクセシビリティ権限がONになっているか
* オーバーレイ権限がONになっているか
* Uber Driverが起動しているか
* オファー画面が実際に表示されているか
* 診断ログがOFFになっていないか

### HUDプレビューが表示されない場合

オーバーレイ権限が許可されているか確認してください。

### 数値がおかしい場合

オファー画面の表示内容やOCRの読み取り状況によって、数値が正しく取得できない場合があります。

再現する場合は、診断ログを詳細診断にしてから再度試し、アップロード機能で報告してください。

### 消費燃料が表示されない場合

車両設定が「車/バイク」になっているか、燃費が入力されているか確認してください。

### 消費カロリーが表示されない場合

車両設定が自転車または徒歩になっているか確認してください。

体重が未入力の場合は、60kgとして計算されます。

### 通知アクセスを求められた場合

現時点のPikDro HUD Demoでは、通知アクセスは使用していません。
通常は通知アクセスを許可する必要はありません。
