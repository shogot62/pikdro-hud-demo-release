# 注意事項・利用条件

最終更新日: 2026年6月19日

この文書は、PikDro HUD Demo の利用に関する注意事項および利用条件を定めるものです。

PikDro HUD Demo をダウンロード、インストール、起動、または利用した時点で、本注意事項・利用条件に同意したものとみなします。

## アプリの位置づけ

PikDro HUD Demo は、Uber Driver のオファー画面に表示される金額・距離・予定時間などをもとに、配達判断を補助するHUDを表示するデモ版・検証版アプリです。

本アプリは、数字や計算が苦手な場合でも、距離単価、分単価、時給換算、1時間あたりの配達件数ペース、消費燃料または消費カロリーなどを確認しやすくすることを目的としています。

本アプリは、配達サービス各社の公式アプリではありません。
また、配達サービス各社と提携、承認、認定、協賛されたものではありません。

## 現在の対応範囲

現時点の主な対応対象は Uber Driver です。

その他の配達アプリへの対応は、今後の検証対象です。
ただし、将来的な対応を保証するものではありません。

## 自動操作について

本アプリは、配達アプリの操作を自動で行うものではありません。

以下のような操作は行いません。

* オファーの自動受諾
* オファーの自動拒否
* 配達アプリ内ボタンの自動タップ
* 配達アプリの設定変更
* 配達サービス上のアカウント操作

本アプリは、画面上の情報をもとに判断補助情報を表示するためのツールです。
最終的な判断および操作は、必ずユーザー自身が行ってください。

## 安全上の注意

本アプリは、配達中・運転中・走行中の画面注視を推奨するものではありません。

利用にあたっては、以下を必ず守ってください。

* 安全確認を最優先してください。
* 交通ルールを守ってください。
* 運転中・走行中に画面を注視しないでください。
* 危険を感じる状況では、本アプリを操作しないでください。
* 停車中または安全な場所で必要な確認を行ってください。
* 各配達サービスの利用規約・ガイドラインを確認し、自己責任で利用してください。

本アプリの表示内容よりも、現実の道路状況、交通ルール、周囲の安全、各配達サービスの指示を優先してください。

## 表示内容・計算結果について

本アプリは、オファー画面から読み取れた情報をもとに、判断補助用の数値を表示します。

主な表示内容には、以下が含まれます。

* 距離単価
* 分単価
* 時給換算
* 1時間あたりの配達件数ペース
* 消費燃料
* 消費カロリー

ただし、これらの表示内容や計算結果が常に正確であることを保証するものではありません。

以下のような理由により、表示されない、または誤った値が表示される場合があります。

* オファー画面の表示形式変更
* OCRの読み取り失敗
* 画面の一部欠け
* 通信状況や端末状態による表示遅延
* 配達アプリ側の仕様変更
* 端末やAndroidバージョンによる動作差
* アクセシビリティやオーバーレイ権限の状態
* デモ版特有の不具合

表示内容は、あくまで判断補助として利用してください。
配達を受けるかどうかの最終判断は、ユーザー自身の責任で行ってください。

## 消費燃料・消費カロリーについて

車/バイクを選択した場合、本アプリは設定された燃費をもとに消費燃料の目安を表示します。

自転車または徒歩を選択した場合、本アプリは設定された体重や予定時間をもとに消費カロリーの目安を表示します。

これらは概算であり、実際の燃料消費量や消費カロリーを保証するものではありません。

実際の値は、車両状態、道路状況、走行速度、積載量、天候、体調、走行方法などによって変動します。

## 必要な権限について

本アプリでは、機能のために主に以下の権限を使用します。

### アクセシビリティ権限

Uber Driver の画面変化を検知し、オファー画面が表示された可能性を判断するために使用します。

また、必要に応じて画面内容の確認やスクリーンショット取得を行い、OCRによる読み取り処理に利用します。

本アプリは、アクセシビリティ権限を利用して配達アプリの操作を自動化するものではありません。

### 他のアプリの上に表示する権限

Uber Driver の画面上に、PikDro HUDやミニアイコンを重ねて表示するために使用します。

この権限が許可されていない場合、HUDやミニアイコンを表示できません。

### 不明なアプリのインストール許可

GitHub Releases からAPKをインストールする場合、Android端末側で「不明なアプリのインストール」を許可する必要がある場合があります。

この許可は、APKをインストールするためのAndroid側の設定です。

## 画像保存について

本アプリには、OCR入力画像を端末内に保存する機能が含まれる場合があります。

画像保存をONにすると、OCRに使用した入力ROI画像が端末の以下の場所に保存されます。

```text
DCIM/PikDro
```

この画像は、ユーザー自身が読み取り状況を確認するためのものです。

`DCIM/PikDro` に保存された確認用画像は、診断アップロードでは送信されません。

ただし、保存された画像には、配達アプリの画面情報が含まれる可能性があります。
画像の閲覧、共有、削除、管理はユーザー自身の責任で行ってください。

個人情報、住所、店舗名、顧客情報、配達先情報などが含まれる可能性のある画像を、第三者に不用意に共有しないでください。

## 診断ログについて

本アプリには、不具合調査のための診断ログ機能が含まれる場合があります。

診断ログは、HUDが表示されない、数値がおかしい、OCRが失敗する、限定オファーが認識されない、挙動が不安定であるなどの問題を調査するために使用します。

診断ログの出力レベルは、主に以下から選択します。

* OFF
* 詳細診断

OFFの場合、診断ログは書き込まれません。
不具合報告を行う場合は、詳細診断をONにしてから再現操作を行ってください。

診断ログには、以下のような情報が含まれる場合があります。

* アプリの動作状態
* 権限状態
* OCRの成功/失敗
* HUD表示状態
* エラー情報
* 処理結果の概要
* 端末内の診断用ファイル名
* アプリ内部の診断イベント

本アプリでは、診断ログに住所、店舗名、顧客名、電話番号、配達先、オファー全文などの機微な情報を残さないよう配慮しています。

ただし、デモ版・検証版であるため、すべての情報が完全に除去されることを保証するものではありません。

## 診断アップロードについて

本アプリには、不具合調査のために診断情報をアップロードする機能が含まれる場合があります。

診断アップロードは、ユーザーがアプリ内の診断画面から「アップロード」または「送信する」を押した場合に実行されます。

診断アップロードでは、以下の情報が含まれる場合があります。

* アプリのバージョン
* 端末情報
* OSバージョン
* 権限状態
* OCRの成功/失敗
* HUD表示状態
* エラー情報
* 診断ログ
* ログ用OCR画像
* ユーザーが入力した不具合コメント

ログ用OCR画像は、アプリ内の診断用保存領域に保存された画像です。
ユーザー確認用として `DCIM/PikDro` に保存された画像は、診断アップロードには含まれません。

アップロードが成功した場合、送信済みの診断ログとログ用画像は端末内から削除されます。

送信された診断情報は、不具合の原因調査、動作改善、修正対応のために利用します。

また、診断情報は調査や修正対応に必要な期間のみ保持され、不要になったログや画像はサーバー上から削除されます。

最新版APKや更新確認に必要なファイルを除き、診断ログや診断画像を恒久的に保存することを目的とするものではありません。

## 不具合コメントについて

診断アップロード時には、不具合の内容をコメントとして入力する必要があります。

コメントには、不具合の状況や再現手順など、調査に必要な内容を記載してください。

コメントには、不具合の状況だけを書いてください。

入力しないでほしい情報の例:

* 住所
* 店舗名
* 顧客名
* 電話番号
* 配達先
* 注文番号
* メールアドレス
* 個人を特定できる内容
* 配達サービスの機密情報

本アプリでは、コメント内の一部情報を自動的に伏せ字化する場合があります。

ただし、すべての個人情報や場所情報を完全に検出・除去できることを保証するものではありません。
コメント入力時は、ユーザー自身でも個人情報や場所を特定できる情報を含めないよう注意してください。

## 外部通信について

本アプリは、通常のHUD表示機能のために、配達アプリの操作内容を外部へ送信することを目的としたものではありません。

ただし、デモ版・検証版では、以下の目的で外部通信を行う場合があります。

* 診断ログや診断情報のアップロード
* アプリの最新版確認
* APKアップデート情報の取得

診断アップロードは、不具合調査のためにユーザーの操作によって実行されます。

最新版確認やアップデート情報の取得は、デモ版の更新案内のために使用される場合があります。

## アップデートについて

本アプリは、GitHub Releases などで配布される最新版情報を確認する場合があります。

最新版がある場合、アプリ内で更新案内が表示されることがあります。

アップデートは任意であり、ユーザーの確認後に行われます。

APKを更新する場合、Android標準のインストール確認画面が表示されることがあります。
ユーザーの確認なしに、通常アプリとしてサイレントインストールを行うものではありません。

## 音声読み上げについて

本アプリには、HUD表示内容を音声で読み上げる機能が含まれる場合があります。

音声読み上げを使用する場合は、周囲の状況、音量、イヤホン利用、交通安全に十分注意してください。

読み上げ内容が常に正確であることを保証するものではありません。
また、音声読み上げが遅延する、途中で途切れる、読み上げられない場合があります。
