# 注意事項・利用条件

最終更新日: 2026年7月15日  
対象バージョン: `0.1.0-demo-305`（versionCode `305`）

PikDro HUD Demoをダウンロード、インストール、起動、または利用した場合、本書の内容に同意したものとみなします。同意できない場合は利用しないでください。

## 位置づけ

本アプリは、Uber Driverのオファー画面から取得できた情報をもとに判断補助情報を表示するデモ版・検証版ツールです。配達サービス各社の公式アプリではなく、提携・承認・認定・協賛を受けたものではありません。

## ユーザー自身が行う操作

本アプリは、オファーの自動受諾、自動拒否、配達アプリ内ボタンの自動タップ、アカウント操作を行いません。配達を受けるかどうかを含む判断と操作は、ユーザー自身が行ってください。

## 安全

- 運転中・走行中に画面を注視または操作しないでください。
- 交通ルール、現実の道路状況、周囲の安全、配達サービスの指示を最優先してください。
- 操作や確認は停車中または安全な場所で行ってください。
- HUDが視界や安全確認を妨げる場合は直ちに利用を中止してください。

## 表示内容

OCR、画面表示、端末状態、配達アプリ側の仕様変更などにより、HUDが表示されない、遅れる、または誤った値になる可能性があります。距離単価、時間単価、時給、燃料、カロリーなどは判断補助または概算であり、正確性・完全性・継続的な利用可能性を保証しません。
