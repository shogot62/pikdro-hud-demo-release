# データ・ログ・画像の扱い

最終更新日: 2026年7月15日  
対象バージョン: `0.1.0-demo-318`（versionCode `318`）

この文書は、PikDro HUD Demoが扱う設定、画面、OCR、画像、診断情報、外部通信について説明します。

## 基本方針

- 通常の画面判定、OCR、計算は端末内で行います。
- オファー候補の検知時だけスクリーンショットを取得し、Uberオファーカードの必要範囲へ切り出してOCRします。
- 配達アプリの自動受諾、自動拒否、自動タップは行いません。
- ユーザー確認用画像と診断用画像を分離します。
- 診断アップロードはユーザーが送信操作をした場合だけ実行します。

## 端末内に保存する情報

アプリ設定として、HUD有効化、表示時間、車両、燃費、体重、色、テーマ、読み上げ、画像保存、診断設定などを端末内に保存します。

設定が有効な場合、HUD表示に使用した確認用OCR入力ROI画像を `Pictures/PikDro` に保存します。全画面画像を通常の確認用画像として保存しません。保存画像はユーザーが確認・削除できますが、アンインストール後も共有領域に残る場合があります。

## 通常扱わない情報

本アプリは、パスワード、決済情報、銀行口座情報、顧客の連絡先、顧客とのメッセージ、配達先情報を取得・保存・送信することを目的としていません。パスワード、アカウント、決済、システム権限などの機微な画面ではキャプチャを抑止します。

## 診断ログ

詳細診断をONにした場合、アプリのversion、端末・OS情報、権限状態、処理段階、OCRの成功・失敗、抽出した数値、HUD状態、エラー、処理時間などを記録する場合があります。

本番診断ログへ生のOCR全文、画面全文、住所、店舗名、顧客名、電話番号、配達先を記録しない設計です。

## 診断アップロード

ユーザーが診断画面で内容を確認し「送信する」を押した場合、次の情報をZIPで送信する場合があります。

- アプリversion、端末、OS、権限状態などの安全なメタデータ
- boundedな診断ログ
- アプリprivate領域へ診断目的で保存した画像
- ユーザーが入力した不具合コメント

`Pictures/PikDro` のユーザー確認用画像はアップロードしません。アップロード成功後は、送信済み診断ログとアプリprivateの診断用画像を端末から削除します。

コメントには住所、店舗名、顧客名、電話番号、配達先、注文番号、メールアドレスなどを書かないでください。自動マスキングですべての個人情報を除去できる保証はありません。

アップロードサーバーでは、受信した診断ZIPをchannel別に保存し、原則として7日を超えたファイルを削除する実装です。障害対応、バックアップ、法令対応などにより削除時期が前後する場合があります。

## GitHubへの通信

GitHub Release Demo版は次の目的でGitHubへHTTPS通信します。

- `update.json` による最新版確認
- ユーザー同意後のAPKダウンロード

設定画面の共有用QRコードは端末内で生成し、表示するだけでは通信しません。「GitHubを開く」を押した場合は公開配布ページのURLをブラウザまたはGitHubアプリへ渡します。「リンクを共有」を押した場合は公開URLと案内文だけをAndroidの共有シートへ渡し、共有先の選択と送信はユーザーが行います。アプリ設定、診断ログ、保存画像、配達情報は共有内容に含めません。

GitHub側で扱われるアクセス情報にはGitHubの規約とプライバシー方針が適用されます。更新は任意で、SHA-256検証後にAndroid標準インストーラーを開きます。

## 利用目的と第三者提供

診断情報は不具合調査、OCR・HUDの改善、端末差の調査、安定性向上に利用します。広告配信、行動追跡、配達員評価、販売を目的として利用しません。

診断情報の保存・通信に必要なホスティング事業者、GitHub、法令に基づく開示、不正利用やセキュリティ対応に必要な範囲では、関連事業者が情報を取り扱う場合があります。

## ユーザーによる管理

アプリ内から確認用画像、診断ログ、診断用画像を削除できます。端末外へ送信済みの診断情報は、送信日時、version、端末情報などで対象を特定できない場合、個別削除が困難なことがあります。

## 変更

機能や配布方法の変更に応じて本書を更新します。更新後に本アプリを利用した場合、更新後の内容が適用されます。
