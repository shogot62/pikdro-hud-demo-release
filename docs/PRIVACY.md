# データ・ログ・画像の扱い

最終更新日: 2026年6月19日

この文書は、PikDro HUD Demo におけるデータ、ログ、画像、診断情報の取り扱いについて説明するものです。

PikDro HUD Demo をダウンロード、インストール、起動、または利用した時点で、本内容に同意したものとみなします。

## 基本方針

PikDro HUD Demo は、Uber Driver のオファー画面に表示される金額・距離・予定時間などをもとに、配達判断を補助するHUDを表示するデモ版・検証版アプリです。

本アプリでは、機能の性質上、画面検知、OCR、HUD表示、診断ログ、画像保存、診断アップロードなどの処理を行う場合があります。

データの取り扱いに関する基本方針は以下です。

* 通常のHUD表示機能のために、配達アプリの操作内容を外部へ送信することを目的としません。
* 配達の受諾・拒否など、配達アプリの操作を自動で行いません。
* 診断アップロードは、不具合調査のためにユーザーが操作した場合に実行されます。
* ユーザー確認用の保存画像と、診断用のログ画像は区別して扱います。
* 不具合調査に不要となった診断ログや診断画像は、必要な期間の経過後に削除します。
* 住所、店舗名、顧客名、電話番号、配達先などの情報を不用意に扱わないよう配慮します。

## 本アプリが扱う可能性のある情報

PikDro HUD Demo では、以下の情報を扱う場合があります。

### アプリ内設定

アプリの動作に必要な設定情報を端末内に保存します。

例:

* HUD有効化の状態
* HUD表示時間
* 車両設定
* 燃費
* 体重
* カラーコーディング設定
* テーマ設定
* 読み上げ設定
* 画像保存設定
* 診断ログ設定

これらの設定は、主に端末内でアプリを動作させるために使用します。

### 権限状態

本アプリは、必要な権限が許可されているかを確認する場合があります。

例:

* アクセシビリティ権限の状態
* オーバーレイ権限の状態
* 不明なアプリのインストール許可の状態

権限状態は、HUD表示や診断のために使用します。

### 画面検知情報

本アプリは、Uber Driver の画面変化を検知し、オファー画面が表示された可能性を判断する場合があります。

この処理は、HUD表示のタイミングを判断するために使用します。

本アプリは、配達アプリの操作を自動化するために画面検知を行うものではありません。

### スクリーンショット・OCR入力画像

本アプリは、オファー画面の情報を読み取るために、必要に応じてスクリーンショット取得や画像切り出しを行い、OCR処理に利用する場合があります。

OCR処理は、金額、距離、予定時間などの判断補助情報を取得するために使用します。

通常の処理では、取得した画像はHUD表示や計算に必要な範囲で使用されます。

画像保存設定や診断ログ設定の状態によっては、OCR入力画像やログ用画像が端末内に保存される場合があります。

## 本アプリが通常扱わない情報

本アプリは、以下の情報を取得・保存・送信することを目的としていません。

* 配達サービスのログインID
* 配達サービスのパスワード
* クレジットカード情報
* 銀行口座情報
* 顧客の連絡先
* 顧客とのメッセージ内容
* 配達サービス上のアカウント操作情報
* オファーの自動受諾・自動拒否の操作情報

ただし、スクリーンショットやOCR入力画像には、画面上に表示されている情報が写り込む可能性があります。

画像保存や診断アップロードを行う場合は、個人情報、住所、店舗名、顧客情報、配達先情報などが含まれないよう注意してください。

## 画像保存について

本アプリには、OCR入力画像を端末内に保存する機能が含まれる場合があります。

画像保存をONにすると、OCRに使用した入力画像が端末の以下の場所に保存されます。

```text
DCIM/PikDro
```

この画像は、ユーザー自身がOCRの読み取り状況を確認するためのものです。

`DCIM/PikDro` に保存された確認用画像は、診断アップロードでは送信されません。

画像保存設定では、以下の操作ができる場合があります。

* 画像保存のON/OFF
* 最新画像の確認
* 保存画像一覧の確認
* 保存画像の削除
* 複数画像のレシート結合

保存された画像には、配達アプリの画面情報が含まれる可能性があります。

画像の閲覧、共有、削除、管理はユーザー自身の責任で行ってください。

個人情報、住所、店舗名、顧客情報、配達先情報などが含まれる可能性のある画像を、第三者に不用意に共有しないでください。

## 診断ログについて

本アプリには、不具合調査のための診断ログ機能が含まれる場合があります。

診断ログは、以下のような問題を調査するために使用します。

* HUDが表示されない
* 数値がおかしい
* OCRが失敗する
* 限定オファーが認識されない
* HUDがすぐ消える
* ミニアイコンが表示されない
* アプリの挙動が不安定である
* 診断アップロードが失敗する

診断ログの出力レベルは、主に以下から選択します。

* OFF
* 詳細診断

OFFの場合、診断ログは書き込まれません。

不具合報告を行う場合は、詳細診断をONにしてから再現操作を行ってください。

診断ログには、以下のような情報が含まれる場合があります。

* アプリの動作状態
* 権限状態
* OCRの成功/失敗
* HUD表示状態
* エラー情報
* 処理結果の概要
* 端末内の診断用ファイル名
* アプリ内部の診断イベント

本アプリでは、診断ログに住所、店舗名、顧客名、電話番号、配達先、オファー全文などの機微な情報を残さないよう配慮しています。

ただし、デモ版・検証版であるため、すべての情報が完全に除去されることを保証するものではありません。

## ログ用画像について

診断ログを詳細診断にしている場合、不具合調査のためにログ用OCR画像がアプリ内の診断用保存領域に保存される場合があります。

ログ用画像は、ユーザー確認用として `DCIM/PikDro` に保存される画像とは別のものです。

主な違いは以下です。

| 種類    | 保存場所          | 主な目的          | 診断アップロード対象  |
| ----- | ------------- | ------------- | ----------- |
| 確認用画像 | `DCIM/PikDro` | ユーザー自身が確認するため | 含まれません      |
| ログ用画像 | アプリ内の診断用保存領域  | 不具合調査のため      | 含まれる場合があります |

診断アップロードが成功した場合、送信済みの診断ログとログ用画像は端末内から削除されます。

## 診断アップロードについて

本アプリには、不具合調査のために診断情報をアップロードする機能が含まれる場合があります。

診断アップロードは、ユーザーがアプリ内の診断画面から「アップロード」または「送信する」を押した場合に実行されます。

ユーザーの操作なしに、通常のHUD表示機能だけで診断ログやログ用画像をアップロードすることを目的としていません。

診断アップロードでは、以下の情報が含まれる場合があります。

* アプリのバージョン
* 端末情報
* OSバージョン
* 権限状態
* OCRの成功/失敗
* HUD表示状態
* エラー情報
* 診断ログ
* ログ用OCR画像
* ユーザーが入力した不具合コメント

送信された診断情報は、不具合の原因調査、動作改善、修正対応のために利用します。

## 不具合コメントについて

診断アップロード時には、不具合の内容をコメントとして入力する必要があります。

コメントには、不具合の状況や再現手順など、調査に必要な内容を記載してください。

コメントに入力してほしい内容の例:

* 何をしようとしていたか
* どの画面で発生したか
* HUDが出なかったのか、数値がおかしかったのか
* 何回くらい発生したか
* 再現しやすい条件があるか

コメントには、以下のような情報を書かないでください。

* 住所
* 店舗名
* 顧客名
* 電話番号
* 配達先
* 注文番号
* メールアドレス
* 個人を特定できる内容
* 配達サービスの機密情報

本アプリでは、コメント内の一部情報を自動的に伏せ字化する場合があります。

ただし、すべての個人情報や場所情報を完全に検出・除去できることを保証するものではありません。

コメント入力時は、ユーザー自身でも個人情報や場所を特定できる情報を含めないよう注意してください。

## 診断情報の利用目的

診断アップロードにより送信された情報は、以下の目的で利用します。

* 不具合の原因調査
* OCR精度の改善
* HUD表示の改善
* 限定オファー検出の改善
* 端末やAndroidバージョンごとの問題調査
* アプリの安定性向上
* ユーザーから報告された不具合への対応

診断情報を、広告配信、行動追跡、第三者への販売、配達員の評価、配達サービス上のアカウント判定などの目的で利用することはありません。

## 外部通信について

PikDro HUD Demo は、通常のHUD表示機能のために、配達アプリの操作内容を外部へ送信することを目的としていません。

ただし、デモ版・検証版では、以下の目的で外部通信を行う場合があります。

* 診断ログや診断情報のアップロード
* アプリの最新版確認
* APKアップデート情報の取得

診断アップロードは、不具合調査のためにユーザーの操作によって実行されます。

最新版確認やアップデート情報の取得は、デモ版の更新案内のために使用される場合があります。

## GitHub Releases について

PikDro HUD Demo は、GitHub Releases を通じてAPKやアップデート確認用ファイルを配布する場合があります。

アプリが最新版確認を行う場合、GitHub上の更新情報や `update.json` などにアクセスする場合があります。

GitHub Releases からAPKをダウンロードする場合、GitHub側でアクセスに関する情報が扱われる可能性があります。

GitHub側で扱われる情報については、GitHubの規約やプライバシーに関する説明を確認してください。

## アップデート確認について

本アプリは、GitHub Releases などで配布される最新版情報を確認する場合があります。

最新版確認では、主に以下の情報を確認します。

* 最新版のバージョン情報
* APKのダウンロードURL
* 更新内容
* SHA-256などの確認用情報

最新版がある場合、アプリ内で更新案内が表示されることがあります。

アップデートは任意であり、ユーザーの確認後に行われます。

APKを更新する場合、Android標準のインストール確認画面が表示されることがあります。

ユーザーの確認なしに、通常アプリとしてサイレントインストールを行うものではありません。

## 通知アクセスについて

現時点のPikDro HUD Demoでは、通知アクセス権限は使用していません。

通常は通知アクセスを許可する必要はありません。

今後の機能追加により変更される可能性はありますが、その場合はアプリ内または関連ドキュメントで案内します。

## データの保存期間

端末内に保存される設定情報は、アプリの利用に必要な範囲で保存されます。

`DCIM/PikDro` に保存された確認用画像は、ユーザーが削除するまで端末内に残る場合があります。

ログ用画像や診断ログは、診断機能やアップロード機能のために一時的に保存される場合があります。

診断アップロードが成功した場合、送信済みの診断ログとログ用画像は端末内から削除されます。

アップロードされた診断情報は、不具合調査や修正対応に必要な期間のみ保持され、不要になったログや画像はサーバー上から削除されます。

最新版APKや更新確認に必要なファイルを除き、診断ログや診断画像を恒久的に保存することを目的とするものではありません。

## 第三者提供について

本アプリは、診断アップロードで送信された情報を、広告配信、販売、配達員の評価、配達サービス上のアカウント判定などの目的で第三者に提供することはありません。

ただし、以下の場合には、必要な範囲で情報が取り扱われる場合があります。

* 診断情報の保存やアップロードに必要なサーバー、ホスティング、通信サービスを利用する場合
* GitHub Releases からAPKや更新確認用ファイルを取得する場合
* 法令に基づき開示が必要となる場合
* 不正利用、障害、セキュリティ上の問題への対応が必要な場合

## セキュリティについて

本アプリでは、診断情報やログ画像の取り扱いに注意し、不必要な情報を保存・送信しないよう努めます。

ただし、デモ版・検証版であるため、すべての不具合、情報漏えい、誤送信、誤保存を完全に防止できることを保証するものではありません。

個人情報、住所、店舗名、顧客情報、配達先情報などが含まれる可能性のある画像やコメントを、第三者に不用意に共有しないでください。

## ユーザーによる削除

ユーザーは、アプリ内の機能により、保存画像や診断ログを削除できる場合があります。

主な削除対象:

* `DCIM/PikDro` に保存された確認用画像
* アプリ内に保存された診断ログ
* アプリ内に保存されたログ用画像

また、PikDro HUD Demo をアンインストールすると、アプリ内に保存された設定や診断データが削除される場合があります。

ただし、`DCIM/PikDro` など端末の共有領域に保存された画像は、アンインストール後も端末内に残る場合があります。

不要な画像は、アプリ内の削除機能または端末のファイル管理アプリから削除してください。

## 端末外に送信した診断情報の削除

診断アップロードにより送信された情報は、不具合調査や修正対応に必要な期間のみ保持され、一定期間の経過後や新しいバージョンのログが生成された場合などに、自動的に削除されます。

ただし、送信日時、アプリバージョン、端末情報、コメント内容など、対象を特定するための情報が不足している場合、該当データを特定できない場合があります。

また、すでに不具合調査や修正対応に利用済みの集計情報、個人を特定できない形に加工された情報、バックアップやログ管理上ただちに削除できない情報については、完全な削除に時間がかかる、または削除できない場合があります。

## 子どもの利用について

本アプリは、配達業務における判断補助を目的としたデモ版・検証版アプリです。

未成年者や配達業務に従事していない方の利用を想定していません。

## 変更について

本ドキュメントは、必要に応じて変更される場合があります。

変更後にPikDro HUD Demoをダウンロード、インストール、起動、または利用した場合、変更後の内容に同意したものとみなします。

## 問い合わせ・不具合報告

不具合が発生した場合は、アプリ内の診断ログ機能を利用して報告できる場合があります。

診断アップロードを行う場合は、個人情報、住所、店舗名、顧客名、電話番号、配達先などをコメントに含めないでください。

送信された診断情報は、不具合の原因調査と修正対応のために利用します。

不具合が発生した場合は、アプリ内の診断ログ機能を利用して報告できる場合があります。

診断アップロードを行う場合は、個人情報、住所、店舗名、顧客名、電話番号、配達先などをコメントに含めないでください。

送信された診断情報は、不具合の原因調査と修正対応のために利用します。

問い合わせや不具合報告は、アプリ内の診断ログ機能から行ってください。現時点では、個別の問い合わせ窓口は設けていません。
