# 困ったとき

最終更新日: 2026年7月15日  
対象バージョン: `0.1.0-demo-308`（versionCode `308`）

## HUD有効化をONにできない

- PikDro HUD DemoのアクセシビリティサービスをONにします。
- 「他のアプリの上に表示」を許可します。
- 設定直後に反映されない場合はアプリを開き直します。

通知アクセス、位置情報、カメラ、マイク、連絡先の許可は不要です。

## ミニアイコンまたはHUDが表示されない

1. HUD有効化とHUD監視状態を確認します。
2. Uber Driverを前面にし、実際のオファー画面で確認します。
3. ミニアイコンを短くタップして手動確認します。
4. 端末の省電力設定でPikDro HUD Demoが強く制限されていないか確認します。
5. 改善しない場合は詳細診断をONにして再現し、診断アップロードを行います。

オファー画面ではない、必要な値を安全に確定できない、機微な画面である、と判断した場合はHUDを表示しません。

## 数値がおかしい・一部出ない

- Uber Driver側の金額、距離、予定時間がすべて見えているか確認します。
- 画面表示サイズや文字サイズが極端でないか確認します。
- 通常と異なる限定オファー画面では読み取りが不安定になる場合があります。
- ミニアイコンの手動確認を試します。
- 詳細診断をONにして再現し、個人情報を含めず報告します。

誤認識が疑われる場合はHUDの値だけで判断しないでください。

## HUDがすぐ消える

「HUD表示時間」を確認します。設定範囲は1〜60秒です。閉じる操作、監視停止、画面状態の変化でも非表示になる場合があります。

## 読み上げされない

- 音声読み上げがONか確認します。
- テンプレートが空でないか確認します。
- 「テスト再生」で確認します。
- 端末音量、マナーモード、Bluetooth出力先を確認します。

## 画像が保存されない

- 「オファー画像の保存」がONか確認します。
- 実際にHUD表示可能なオファーとして処理されたか確認します。
- `Pictures/PikDro` をファイルアプリで確認します。
- 端末の空き容量を確認します。

全画面画像ではなく、実際にOCRとHUD表示へ使用した確認用ROI画像のみが保存対象です。

## 診断アップロードできない

- GitHub Release Demo版または診断対応のdevelopment版か確認します。
- インターネット接続を確認します。
- 診断アップロード先が設定されているか確認します。
- 詳細診断をONにし、問題を再現してから送信します。
- コメント欄へ問題の状況を入力します。個人情報は入力しません。

`Pictures/PikDro` の確認用画像は診断アップロードされません。

## アップデート通知が出ない

- 「最新版を確認」を手動で押します。
- インターネット接続を確認します。
- 最新のGitHub Releaseがdraftやprereleaseではなく通常リリースか確認します。
- 現在のversionCodeが公開版以上なら通知されません。

## APKを更新できない

- 「不明なアプリのインストール」をPikDro HUD Demoに許可します。
- 端末の空き容量を確認します。
- APKを再ダウンロードします。
- 現在のアプリと更新APKの署名が同じである必要があります。

署名不一致時にアンインストールすると、アプリ設定が失われる場合があります。通常更新では同一署名のAPKを使用してください。

## 共有QRまたはGitHubリンクを開けない

- QRコードを読み取る側の端末がインターネットへ接続されているか確認します。
- 「GitHubを開く」で反応しない場合は、ブラウザまたはGitHubアプリが利用できるか確認します。
- 「リンクを共有」で共有先が出ない場合は、共有を受け取れるアプリが端末にあるか確認します。
- Demo配布リポジトリが公開状態でない場合、第三者はページを開けません。

## 端末が重い・熱い・電池消費が多い

- 使用しないときはHUD有効化をOFFにします。
- 詳細診断と画像保存をOFFにします。
- 他の負荷が高いアプリを閉じます。
- 端末が熱い場合は安全な場所で利用を中止します。

## 利用を中止すべき場合

HUDが安全確認を妨げる、端末が不安定になる、配達アプリの操作に支障が出る、誤った値が続く場合は利用を中止してください。安全、交通ルール、各サービスの規約を最優先してください。
