# 困ったとき

このページでは、PikDro HUD Demo がうまく動かない場合の確認方法をまとめています。

PikDro HUD Demo はデモ版・検証版のため、端末、Androidバージョン、Uber Driver側の画面変更、権限状態などによって動作が不安定になる場合があります。

不具合が再現する場合は、診断ログをONにしてから再度試し、アプリ内の診断アップロード機能から報告してください。

## まず確認すること

うまく動かない場合は、最初に以下を確認してください。

* PikDro HUD Demo の「HUD有効化」がONになっているか
* アクセシビリティ権限がONになっているか
* オーバーレイ権限がONになっているか
* Uber Driverが起動しているか
* Uber Driver上で実際にオファー画面が表示されているか
* PikDro HUD Demoのバージョンが古くないか
* 端末の省電力設定でPikDro HUD Demoが制限されていないか

## APKをインストールできない

GitHub Releases からダウンロードしたAPKをインストールできない場合は、以下を確認してください。

### 「不明なアプリをインストールできません」と表示される

Androidの設定で、APKを開いたアプリに対して「不明なアプリのインストール」を許可してください。

例:

1. Androidの設定を開きます。
2. アプリ設定を開きます。
3. APKを開いたアプリを選択します。

   * Chrome
   * ファイル
   * Files by Google
   * その他のブラウザ
4. 「不明なアプリのインストール」を許可します。
5. もう一度APKを開きます。

画面名は端末やAndroidバージョンによって異なる場合があります。

### 「アプリはインストールされていません」と表示される

以下の可能性があります。

* すでに別の署名のPikDro HUD Demoが入っている
* 古いバージョンへ戻そうとしている
* APKファイルのダウンロードに失敗している
* 端末の空き容量が不足している

対処方法:

* 端末の空き容量を確認してください。
* APKを再ダウンロードしてください。
* 既存のPikDro HUD Demoをアンインストールしてから、再度インストールしてください。

ただし、アンインストールするとアプリ内設定や保存データが消える場合があります。

### Play Protectの警告が出る

GitHub Releasesから配布しているAPKは、Google Play経由のインストールではないため、端末によって警告が表示される場合があります。

内容を確認し、自己責任でインストールしてください。

不安がある場合は、インストールしないでください。

## アプリを起動できない

PikDro HUD Demoが起動しない、またはすぐ閉じる場合は、以下を試してください。

* 端末を再起動する
* PikDro HUD Demoを最新版に更新する
* Androidの設定からPikDro HUD Demoのキャッシュを削除する
* それでも改善しない場合は、再インストールする

再インストールすると、アプリ内設定や保存データが消える場合があります。

## アクセシビリティ権限をONにできない

PikDro HUD Demoは、Uber Driverの画面変化を検知するためにアクセシビリティ権限を使用します。

アクセシビリティ権限をONにできない場合は、以下を確認してください。

* PikDro HUD Demoが正しくインストールされているか
* Androidの設定でPikDro HUD Demoがアクセシビリティ一覧に表示されているか
* 端末のセキュリティ設定や管理者設定で制限されていないか
* 一度アプリを再起動してから、もう一度設定画面を開く
* 端末を再起動する

Androidのバージョンや端末によって、ダウンロードしたAPKに対するアクセシビリティ許可が制限される場合があります。

その場合は、Androidの設定画面上に表示される案内に従ってください。

## オーバーレイ権限を許可できない

HUDやミニアイコンを表示するには、「他のアプリの上に表示」権限が必要です。

オーバーレイ権限を許可できない場合は、以下を確認してください。

* Androidの設定でPikDro HUD Demoに「他のアプリの上に表示」を許可しているか
* 画面フィルター系アプリやブルーライトカット系アプリが干渉していないか
* 端末の省電力設定でバックグラウンド動作が制限されていないか
* 端末を再起動する

オーバーレイ権限がない場合、HUDプレビュー、HUD表示、ミニアイコン表示は動作しません。

## HUD有効化をONにできない

PikDro HUD Demoの「HUD有効化」をONにできない場合は、必要な権限が不足している可能性があります。

確認する項目:

* アクセシビリティ権限
* オーバーレイ権限

権限を許可した直後に反映されない場合は、PikDro HUD Demoを一度閉じてから開き直してください。

## ミニアイコンが表示されない

ミニアイコンが表示されない場合は、以下を確認してください。

* HUD有効化がONになっているか
* オーバーレイ権限がONになっているか
* PikDro HUD Demo本体画面ではなく、他のアプリ画面を開いているか
* 端末の省電力設定でPikDro HUD Demoが制限されていないか

ミニアイコンは、HUD監視がONで、PikDro HUD Demo本体画面以外を表示しているときに表示される場合があります。

## HUDが表示されない

Uber Driverでオファー画面が出ているのにHUDが表示されない場合は、以下を確認してください。

* PikDro HUD Demoの「HUD有効化」がONになっているか
* アクセシビリティ権限がONになっているか
* オーバーレイ権限がONになっているか
* Uber Driverのオファー画面表示中に発生しているか
* 発生したタイミングや画面の状態に心当たりがないか
* ミニアイコンをタップして手動チェックを試したか
* 診断ログがOFFになっていないか

それでも表示されない場合は、以下の流れで不具合報告してください。

1. PikDro HUD Demoを開きます。
2. 「診断ログ」を開きます。
3. ログ出力を「詳細診断」にします。
4. Uber Driverでオファーを待ちます。
5. HUDが表示されない状態を再現します。
6. PikDro HUD Demoに戻ります。
7. 診断ログからアップロードします。
8. コメント欄に「オファー画面は出ていたがHUDが表示されない」と入力します。

## HUDは出るが、すぐ消える

HUDがすぐ消える場合は、HUD表示時間を確認してください。

確認する場所:

* 表示設定
* HUD表示時間

HUD表示時間は 1〜60秒 の範囲で設定できます。

また、オファー画面が消えた、またはオファー画面ではないと判断された場合、設定時間の経過後にHUDが非表示になる場合があります。

## HUDの数値がおかしい

距離単価、分単価、時給換算、ペース、消費燃料、消費カロリーなどの数値がおかしい場合は、OCRの読み取り失敗や画面表示の変化が原因の可能性があります。

よくある原因:

* 金額を正しく読み取れていない
* 距離を正しく読み取れていない
* 予定時間を正しく読み取れていない
* Uber Driver側の画面表示が変わった
* 画面の一部が隠れている
* 端末の表示サイズや文字サイズの影響を受けている
* 限定オファーなど通常と違う画面形式になっている

対処方法:

* もう一度オファー画面を表示して確認する
* ミニアイコンをタップして手動チェックする
* 表示サイズや文字サイズを極端に大きくしている場合は標準に近づける
* 診断ログを詳細診断にして再現し、アップロードする

不具合コメントには、以下のように書いてください。

```text
HUDは表示されたが、距離単価が明らかにおかしい値になりました。
```

```text
金額は合っているように見えますが、距離が正しく読めていないようです。
```

## 限定オファーでHUDが出ない、または数値がおかしい

限定オファーは通常のオファー画面と表示形式が異なる場合があり、検出やOCRが不安定になることがあります。

確認すること:

* HUD有効化がONになっているか
* アクセシビリティ権限がONになっているか
* オーバーレイ権限がONになっているか
* ミニアイコンの手動チェックを試したか
* 診断ログを詳細診断にして再現したか

限定オファーで不具合が出る場合は、診断アップロードで報告してください。

コメント例:

```text
限定オファーの画面でHUDが表示されませんでした。
```

```text
限定オファーではHUDは出たが、数値が正しくありませんでした。
```

## 消費燃料が表示されない

消費燃料は、車両設定が「車/バイク」の場合に表示されます。

確認すること:

* 車両設定が「車/バイク」になっているか
* 燃費が入力されているか
* オファー距離が正しく読み取れているか

燃費が未入力、または距離が読み取れていない場合、消費燃料が正しく表示されない場合があります。

## 消費カロリーが表示されない

消費カロリーは、自転車または徒歩系の車両設定の場合に表示されます。

確認すること:

* 車両設定が以下のいずれかになっているか

  * 電動自転車
  * ママチャリ
  * クロス/ロードバイク
  * 徒歩
* 予定時間が正しく読み取れているか
* 体重設定が入力されているか

体重が未入力の場合は、標準値として60kgが使用されます。

## 音声読み上げされない

音声読み上げが動作しない場合は、以下を確認してください。

* 読み上げ設定がONになっているか
* 端末の音量が小さすぎないか
* マナーモードやサイレントモードになっていないか
* Bluetoothイヤホンやスピーカーの接続先が正しいか
* 読み上げテンプレートが空になっていないか
* テスト再生で音が出るか

テスト再生で音が出る場合、実際のHUD表示時に読み上げ条件を満たしていない可能性があります。

## HUDプレビューが表示されない

HUDプレビューが表示されない場合は、オーバーレイ権限を確認してください。

確認すること:

* オーバーレイ権限がONになっているか
* PikDro HUD Demoが省電力設定で制限されていないか
* 端末を再起動しても改善するか

HUDプレビューは、実際のオファー画面を待たずにHUD表示を確認するための機能です。

## 画像が保存されない

画像保存をONにしているのに画像が保存されない場合は、以下を確認してください。

* 画像保存設定がONになっているか
* 実際にOCR処理が実行されているか
* 端末の空き容量が不足していないか
* 保存先 `DCIM/PikDro` を確認したか
* Androidの写真/ファイルアプリを更新して再表示したか

保存された画像は、ユーザーがOCR入力画像を確認するためのものです。

診断アップロードでは、`DCIM/PikDro` の確認用画像は送信されません。

## 保存画像一覧に画像が出ない

保存画像一覧に画像が出ない場合は、以下を確認してください。

* 画像保存設定がONになっているか
* OCR処理が実際に行われたか
* `DCIM/PikDro` に画像が存在するか
* 端末の写真アプリではなく、ファイルアプリから確認したか

端末によっては、保存直後に写真アプリへ反映されるまで時間がかかる場合があります。

## レシート結合がうまくいかない

複数画像のレシート結合がうまくいかない場合は、以下を確認してください。

* 結合対象の画像が複数あるか
* 画像ファイルが削除されていないか
* 端末の空き容量が不足していないか
* 非常に大きな画像を大量に選択していないか

レシート結合では、保存された複数の画像を縦方向に連結して1枚にまとめます。

## 診断ログが記録されない

診断ログが記録されない場合は、ログ出力がOFFになっている可能性があります。

確認すること:

* 診断ログを開く
* ログ出力を「詳細診断」にする
* 不具合を再現する
* もう一度ログを確認する

OFFの場合、診断ログは書き込まれません。

## 診断アップロードできない

診断アップロードに失敗する場合は、以下を確認してください。

* インターネット接続があるか
* 電波状況が悪くないか
* 診断ログが詳細診断になっているか
* 不具合コメントを入力しているか
* アップロード対象のログやログ用画像が存在するか
* しばらく時間を置いて再試行したか

アップロードが成功した場合、送信済みの診断ログとログ用画像は端末内から削除されます。

ユーザー確認用として `DCIM/PikDro` に保存された画像は、診断アップロードには含まれません。

## 不具合コメントに何を書けばいいか

不具合コメントには、個人や場所を特定できる情報を書かず、不具合の状況だけを書いてください。

書いてほしい内容:

* 何をしようとしていたか
* どの画面で発生したか
* HUDが出なかったのか、数値がおかしかったのか
* 何回くらい発生したか
* 再現しやすい条件があるか

書かないでほしい内容:

* 住所
* 店舗名
* 顧客名
* 電話番号
* 配達先
* 注文番号
* メールアドレス
* 個人を特定できる内容
* 配達サービスの機密情報

コメント例:

```text
オファー画面は表示されていたが、HUDが出ませんでした。
```

```text
HUDは表示されたが、距離単価が明らかにおかしい値になりました。
```

```text
限定オファーの画面で、何度かHUDが表示されませんでした。
```

## アップデート通知が出ない

PikDro HUD Demoは、最新版情報を確認する場合があります。

アップデート通知が出ない場合は、以下を確認してください。

* インターネット接続があるか
* GitHub Releasesに新しいバージョンが公開されているか
* 現在のアプリがすでに最新版ではないか
* アップデート確認がまだ実行されていないだけではないか

最新版確認は、常に即時実行されるとは限りません。

## アップデートできない

最新版APKをダウンロードしても更新できない場合は、以下の可能性があります。

* 現在のAPKと署名が異なる
* 現在のAPKより古いバージョンを入れようとしている
* APKのダウンロードに失敗している
* 端末の空き容量が不足している
* 「不明なアプリのインストール」が許可されていない

対処方法:

* APKを再ダウンロードする
* 端末の空き容量を確認する
* 不明なアプリのインストール許可を確認する
* それでも失敗する場合は、既存アプリをアンインストールしてからインストールする

アンインストールすると、アプリ内設定や保存データが消える場合があります。

## 通知アクセスを求められた場合

現時点のPikDro HUD Demoでは、通知アクセスは使用していません。

通常は通知アクセスを許可する必要はありません。

もし端末設定や他アプリの案内で通知アクセスが表示された場合でも、PikDro HUD Demoの通常利用では許可不要です。

## バッテリー消費が大きい

PikDro HUD Demoは、アクセシビリティ、オーバーレイ表示、OCR処理などを使用するため、利用状況によってはバッテリー消費が増える場合があります。

気になる場合は、以下を試してください。

* 使用しないときはHUD有効化をOFFにする
* 診断ログをOFFにする
* 画像保存をOFFにする
* 不要なHUDプレビューを閉じる
* 端末を充電できる状態で利用する

## 端末が重い、熱くなる

端末が重くなる、熱くなる場合は、以下を試してください。

* HUD有効化をOFFにする
* 診断ログをOFFにする
* 画像保存をOFFにする
* 他のアプリを閉じる
* 端末を再起動する
* しばらく利用を中止する

端末の動作が不安定な状態での利用は避けてください。

## どうしても直らない場合

以下の流れで不具合報告してください。

1. PikDro HUD Demoを開きます。
2. 「診断ログ」を開きます。
3. ログ出力を「詳細診断」にします。
4. 不具合を再現します。
5. PikDro HUD Demoに戻ります。
6. 診断ログからアップロードします。
7. コメント欄に不具合の状況を書きます。
8. 「送信する」を押します。

送信された診断情報は、不具合の原因調査と修正対応に利用します。

ただし、すべての不具合が必ず修正されることを保証するものではありません。

## 利用を中止したほうがよい場合

以下の場合は、無理に利用を続けず、PikDro HUD Demoの利用を中止してください。

* HUD表示が安全確認の妨げになる
* 端末の動作が不安定になる
* 配達アプリの操作に支障が出る
* 数値が明らかにおかしい状態が続く
* 権限設定や動作に不安がある
* その他、利用を継続することが危険または不適切だと感じる

安全確認、交通ルール、各配達サービスの規約を最優先してください。
